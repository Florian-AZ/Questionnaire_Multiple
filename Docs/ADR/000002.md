# ADR 000002 — Choix de MySQL pour la base de données

## Statut

Accepté

## Contexte

Notre projet consiste à développer une application de questionnaire à choix multiples (QCM).

Nous avons besoin d'une base de données pour stocker les informations nécessaires au fonctionnement de l'application, notamment les questionnaires, les questions et les réponses.

Nous devons donc choisir un système de gestion de base de données adapté au projet.

## Décision

Nous avons choisi d'utiliser **MySQL** comme système de gestion de base de données.

Pour le développement local, nous utilisons **MAMP**, qui nous permet notamment de faire fonctionner MySQL sur nos machines.

## Pourquoi ce choix ?

Nous avons choisi MySQL car :

- il est adapté au stockage de données structurées ;
- il permet de gérer les relations entre les différentes données du questionnaire ;
- il est suffisamment simple pour les besoins de notre projet ;
- il est adapté à un projet de petite taille ;
- MAMP permet de mettre en place facilement MySQL en local ;
- nous pouvons utiliser des requêtes SQL pour ajouter, modifier, supprimer et récupérer les données.

## Alternatives envisagées

Nous aurions pu utiliser d'autres systèmes de gestion de bases de données, comme **PostgreSQL** ou **SQLite**.

Nous avons choisi MySQL car il correspond aux besoins de notre projet et peut être facilement utilisé dans notre environnement de développement avec MAMP.

## Conséquences

### Conséquences positives

- Les données du questionnaire sont stockées de manière structurée.
- MySQL permet de gérer les relations entre les différentes tables.
- Les données peuvent être facilement récupérées et modifiées avec SQL.
- MAMP facilite l'utilisation de MySQL en local.
- La base de données peut évoluer si de nouvelles fonctionnalités sont ajoutées.

### Conséquences négatives

- Chaque membre doit disposer d'un environnement MySQL correctement configuré.
- La structure de la base de données doit être définie et respectée par l'équipe.
- Des différences de configuration entre les environnements locaux peuvent entraîner des problèmes.

## Conclusion

MySQL a été retenu comme système de gestion de base de données car il répond aux besoins de notre application de QCM et permet de stocker efficacement les questionnaires, les questions et les réponses.

MAMP est utilisé pour faciliter la mise en place et l'utilisation de MySQL dans notre environnement de développement local.
